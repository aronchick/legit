# Private preview tester guide

Status: draft. The candidate has not been deployed or tested by an external reviewer.

Choose a public PR you know well. Pick a simulated maintainer whose project experience is relevant, then run the review. These are generated interpretations of public history, not comments written or endorsed by the named maintainers.

For each result, mark useful, wrong, or missed something. Add the specific code location and why it matters. A review that correctly finds nothing is useful too; please distinguish that from a review that overlooks a problem you already know about.

For the first session, record:

1. Could you finish without help?
2. Did any comment identify a real issue or useful tradeoff?
3. Which comments were wrong or unnecessary?
4. What significant issue did it miss?
5. Did the priorities resemble the named maintainer, and would you use it again?

The initial samples are bounded and vary by persona; they do not represent anyone's complete career or current views. Evaluation reconstructs reviewed code with an inferred base and remains exploratory. No aggregate quality claim is established yet.
